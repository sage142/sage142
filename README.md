# Square Obby Online (Fake Multiplayer)

A small 2D Roblox-style obby game made with pure Python + Tkinter.

## Features
- Square-player platforming and jump physics
- Obstacle course with lava hazards and finish pad
- Roblox-inspired side panel UI (players, chat, controls)
- Fake multiplayer bots that move and send chat messages

## Run
```bash
python obby2d.py
```

No external dependencies are required.
